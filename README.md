# 고객 설문 리스트 생성기

## 실행

이 폴더의 **실행.cmd**를 더블클릭하면 브라우저에 프로그램이 열립니다. 현재 PC에 있는 Codex Python 환경을 사용하므로 별도 설치가 필요 없습니다. 실행 창은 사용 중 열어 두세요. 종료하려면 실행 창에서 Ctrl+C를 누르거나 창을 닫습니다.

고객 정보는 PC 내부의 `127.0.0.1`에서만 처리됩니다. 외부 전송이나 이메일 발송 기능은 없습니다. 원본 파일은 변경하지 않습니다. 프로그램 종료·브라우저 새로고침 전에 결과를 저장하세요. 여러 창을 동시에 열어 다른 자료를 작업하지 마세요.

다른 PC에서는 Python 3.10 이상을 설치하고 `python -m pip install -r requirements.txt` 실행 후 `python app.py`로 시작할 수 있습니다.

## 사용 순서

1. 두 프로그램에서 내려받은 **.xlsx 또는 .xlsm** 파일을 각각 선택합니다. 구형 .xls 파일은 Excel에서 .xlsx로 다시 저장해 주세요. 암호 파일은 암호를 해제한 사본이 필요합니다.
2. 각 파일의 **시트와 제목 행**을 선택합니다. 첫 30행 중 제목 행을 선택할 수 있습니다.
3. 자료 1·2 모두 **성(Last Name)**과 **이름(First Name)**을 각각 연결합니다. 통합 성명 한 칸을 임의로 분리하지 않으므로, 원본이 성명 한 열이면 성·이름 열을 준비해 주세요. 두 값을 합쳐 담당자를 식별하고, 저장 파일에는 성·이름 및 합친 성명을 보존합니다. 항목별로 원본 열을 연결합니다. 이름이 일치하면 자동 연결하지만 반드시 확인하세요. **고객번호는 두 파일 모두 필수**입니다. 없는 항목은 ‘연결 안 함’으로 둡니다.
4. **자료 1은 기입날짜**, **자료 2는 Install Date** 열을 연결합니다. 각 자료에 맞는 날짜 열을 자동 연결하며, 다른 이름이면 직접 선택합니다. 두 자료의 날짜를 비교하여 같은 우선순위·직급에서는 가장 최신 정보를 선택합니다. 날짜가 없으면 검토 후 수동 확정합니다.
5. 현재 주소 열을 연결하고, 주소에서 찾을 부서 키워드를 확인한 뒤 **고객 목록 생성**을 누릅니다.
6. **확인 필요** 필터에서 각 고객의 **검토** 버튼을 누릅니다. 후보를 선택하거나 연락처를 직접 수정하고, 담당자 직급 및 최신 정보 확인에 체크하여 확정합니다. 기계/모델/고객번호 문제는 원본을 수정한 뒤 다시 불러옵니다.
7. **엑셀로 저장**을 눌러 브라우저 다운로드 폴더에 결과를 저장합니다.

실제 자료를 넣기 전 **가상 예제로 살펴보기**를 누르면 프로그램 흐름을 확인할 수 있습니다. 예제의 고객과 연락처는 모두 가상입니다.

## 선정 규칙

- 자료 1·2의 연락처는 **전화**와 **휴대폰**으로 각각 연결·수정·저장합니다. 둘 중 하나가 있으면 연락처 조건을 충족합니다. 입력된 번호의 형식 오류는 확인 대상으로 표시합니다.

- 기존 구매권한 연결 항목은 **직급**으로 변경되었습니다. 직급을 읽고 표시하며, 주소 키워드에 해당하는 1순위가 없는 고객에 한하여 **대표 → 사장 → 실장 → 팀장** 순서로 2순위 담당자를 선정합니다. 이름·연락처·이메일이 모두 있고 형식 검증을 통과한 후보만 사용합니다. 같은 직급은 최신 정보 순입니다.

- 고객번호는 **정확히 일치할 때만** 통합합니다. 앞자리 0이 있는 텍스트 번호와 숫자 표시 형식은 가능한 범위에서 보존합니다. `0012`와 `12`는 서로 다른 고객입니다. 이미 원본에서 사라진 0은 추측해 붙이지 않습니다.
- 동일 고객의 설치 기계를 모두 보존합니다. 결과의 기계번호·모델명은 **같은 순서로 줄바꿈**하여 짝을 맞춥니다. ‘설치 기계’ 시트에는 기계당 한 행으로 저장합니다.
- 현재 주소에 부서 키워드(기본: 총무, 인사, 경영지원, 구매)가 있으면 1순위 후보입니다. 1순위 후보가 없으면 직급 기준으로 2순위를 찾습니다. 1순위 후보가 있지만 정보가 불완전하면 2순위로 자동 대체하지 않고 확인 필요로 남깁니다. 부서 열은 필터에 사용하지 않습니다. **주소의 부서명이 구매 담당임을 보장하지는 않습니다.** 실제 발송 전 담당자 적합성을 확인하세요.
- 같은 이름의 새 기록은 이전 담당자 기록보다 우선합니다. 동명이인 구분 정보가 없으므로 동명이인이 있는 자료는 원본 후보를 검토하세요.
- 1순위 후보부터 선정하고, 같은 순위에서는 가장 최근 수정일의 행을 선택합니다. 목록과 저장 파일도 1순위부터 표시합니다. **이름·연락처·이메일은 한 원본 행에서 가져오고 서로 다른 행의 정보를 자동으로 조합하지 않습니다.** 최신 행이 불완전해도 과거의 완전한 행으로 대체하지 않습니다. 검토 화면에서 원본 후보를 비교해 보완할 수 있습니다.
- 고객사명·지역·기계별 모델은 최신 날짜의 비어 있지 않은 값을 사용합니다. 같은 날짜의 충돌이나 날짜 없는 상충 값은 확인 대상으로 분리합니다.
- 자동 대상에는 **요청한 8개 항목이 모두 있어야 하며**, 이름·연락처·이메일 누락이나 형식 오류를 허용하지 않습니다. 형식 검증은 이메일 실재 여부나 전화 연결 여부를 확인하는 기능은 아닙니다.
- 날짜 누락, 해석 실패, 미래 날짜, 동일 최신 날짜의 연락처 충돌, 원본 수식 오류, 여러 고객에 걸친 같은 기계번호 등은 확인 필요로 분리합니다.
- 고객번호 없는 행은 고객에 임의로 연결하지 않습니다. 저장 파일의 ‘확인 필요’에 원본 위치를 남깁니다.
- 수동 확정은 담당자 직급·최신 정보·충돌을 사용자가 확인했다는 의미입니다. 최종 수정값, 확인일, 원본 출처를 저장합니다. 원본에는 없는 퇴사/철거/계약종료 상태는 자동 판단하지 않습니다.

직급은 대표·대표이사를 대표로, 사장은 정확히 일치하는 값으로 인식합니다. 경영지원실장·영업팀장처럼 실장·팀장으로 끝나는 직급도 지원합니다. 부사장·부실장·부팀장·대표대행은 자동 후보에 포함하지 않습니다. 날짜나 다른 필수 정보가 부족하면 확인 필요로 분리됩니다.

## 저장 파일

| 시트 | 내용 |
|---|---|
| 설문 대상 | 고객번호당 1명, 필수 8개 항목과 현재 주소·직급·선정 순위·근거·출처 |
| 확인 필요 | 제외된 고객/고객번호 없는 행과 확인 사유 |
| 설치 기계 | 고객별 기계번호·모델명 대응과 출처 |
| 원본 통합 | 연결한 원본 항목과 파일·시트·행 위치 |

처리 기준은 파일당 30MB, 선택 시트당 100,000행, 300열 이하입니다. 날짜는 Excel 날짜 또는 `YYYY-MM-DD`, `YYYY/MM/DD`, `YYYY.MM.DD`, `YYYYMMDD`, ISO 날짜·시간 등을 지원합니다. 수식은 실행하지 않고 Excel에 저장된 계산값을 읽습니다. 계산값이 없으면 Excel에서 계산 후 저장해야 합니다.

실제 고객 파일은 제공되지 않아 가상 자료로 검증했습니다. 실제 열 이름은 연결 화면에서 선택할 수 있습니다.

## 개발 검증

`python -m unittest discover -s tests -v`

구성: `core.py`는 통합·선정 규칙, `excel_io.py`는 Excel 입출력, `app.py`는 로컬 서버, `web/`는 사용자 화면입니다.
