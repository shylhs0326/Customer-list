# 설문 대상 고객 리스트 생성기

두 Excel 파일을 PC 안에서 처리하는 프로그램. Python 표준 HTTP 서버와 로컬 브라우저 화면, openpyxl을 사용한다. 외부 서버 전송과 이메일 발송은 하지 않는다.

입력은 .xlsx/.xlsm, 파일별 시트·제목 행·열 연결을 사용자가 선택한다. 고객번호는 필수 연결이며 나머지 열은 없는 경우 빈칸으로 유지한다. 번호의 앞자리 0과 Excel 표시 형식을 보존한다. 수정일은 고객/담당자 정보의 수정일이어야 한다.

고객번호별 모든 기계와 모델의 대응을 보존한다. 고객사명·지역과 기계별 모델은 최신 유효 날짜의 비어 있지 않은 값으로 결정한다. 날짜가 없는 상충 값과 같은 날짜의 충돌은 검토한다. 담당자는 구매권한 명시 또는 사용자 설정 부서 키워드로 후보화하고, 명시적 권한 없음은 배제한다. 최신 후보 행의 이름·연락처·이메일을 한 묶음으로 사용한다. 서로 다른 행의 개인 연락처를 자동 조합하지 않는다. 최신 후보의 연락처가 불완전하면 과거 후보로 자동 대체하지 않는다. 날짜 없음, 날짜 해석 실패, 미래 날짜, 후보 충돌 및 필수 정보 누락은 확인 필요이다.

사용자는 고객별 후보를 확인하고 값을 수정한 뒤 구매권한·최신 정보 확인을 명시하여 확정할 수 있다. 확인 시에도 필수 8항목과 연락처·이메일 형식은 검증한다. 내보내기는 설문 대상/확인 필요/설치 기계/원본 통합 4개 시트를 포함하며 출처와 선정 근거를 보존한다. 고객번호당 설문 대상은 최대 1행이다.

실제 자료는 제공되지 않았으므로 가상 예제와 경계조건으로 검증하고, 실제 파일 적용 검증은 별도임을 안내한다.
