담당자 선정 기준 및 주의사항

현재 주소에 총무·인사·경영지원·구매 키워드가 포함된 담당자를 1순위로 선정합니다. 1순위 후보가 없으면 이름·연락처·이메일이 모두 있는 담당자 중 대표 → 사장 → 실장 → 팀장 순서로 2순위를 선정합니다. 같은 직급에서는 최신 정보를 선택합니다. 1순위 후보가 있으나 정보가 불완전하면 자동 대체하지 않고 확인 필요로 남깁니다. 같은 순위에서는 최신 정보를 선택하고, 결과 목록과 저장 파일도 1순위부터 표시합니다. 전화 또는 휴대폰 중 하나가 있어야 연락처 조건을 충족합니다. 이름·이메일 등 필수 정보가 없으면 확인 필요로 분리합니다.

자료 1은 기입날짜, 자료 2는 Install Date 열을 연결하세요. 두 자료의 날짜를 함께 비교하여 같은 우선순위·직급에서는 가장 최신 정보를 선택합니다. 날짜가 없으면 직접 확인이 필요합니다. 이름·연락처·이메일은 같은 원본 행에서 가져옵니다.

고객번호는 정확히 일치할 때만 통합합니다. 여러 기계는 같은 순서의 줄바꿈으로 기계번호와 모델명을 보존하며, 원본에 없는 철거·퇴사 여부는 판단할 수 없습니다.
